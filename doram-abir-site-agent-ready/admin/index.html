עומק גלילה

מפת קליקים (עמוד הבית)

כל נקודה מייצגת קליק אחד, לפי המיקום היחסי בעמוד.

שאל את הנתונים

שאלו בעברית חופשית על ביקורים, מקורות, לידים וכפתורים. התשובות מבוססות על נתוני האתר בטווח הנבחר למעלה. ל-AI נשלחים נתונים מצטברים ולידים בלי שם, טלפון או אימייל.

מחולל קישורים עם מעקב (UTM)

צרו קישור לכל פוסט או מודעה כדי לדעת בדיוק איזה ערוץ מביא כניסות ולידים. הדביקו את הקישור בביו, בסטורי או בקמפיין.

התראה במייל על ליד חדש

כדי לקבל מייל מיידי בכל ליד: ב-Netlify (Project configuration ← Environment variables) הוסיפו RESEND_API_KEY (מפתח חינמי מ-resend.com) ו-NOTIFY_EMAIL (המייל שלכם), ובצעו Deploy מחדש.

עריכת תוכן ותמונות

כל שינוי נשמר מיד באתר החי, ללא צורך במתכנת. גרסה קודמת נשמרת אוטומטית בטאב "גרסאות".
